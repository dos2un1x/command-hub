dc
===

GNU 逆波兰计算器，用栈和单字母命令完成任意精度计算。

## 补充说明

dc 是 bc 软件包里的逆波兰（后缀）计算器：先压入操作数，再给出运算符，适合快速计算、脚本求值和交互式栈操作。它支持任意精度整数，小数位数由 `k` 单独控制。

它的输入是一串以空白分隔的 token，而不是常见的表达式语法；负数用 `_` 前缀，结果要靠 `p` 等命令打印。日常可读性更好的替代是 bc（中缀）、`awk`、`python3 -c`，纯整数场景则优先用 shell 的 `$(( ))`。

### 常用示例

```shell
# 2 + 3；p 打印栈顶并换行
echo '2 3 + p' | dc

# 设置 10 位小数，计算 sqrt(2)
dc -e '10 k 2 v p'

# 负数用 _ 前缀；存入寄存器 a 再取回
dc -e '_5 sa la 2 \* p'

# 查看整个栈（栈顶在左）
dc -e '1 2 3 f'
```

## 易错点与排错

- 直接执行 `dc 2 3 +` 不会按预期计算：dc 从标准输入读命令，非交互时用 `-e` 或管道；无参数运行会一直等待输入，看起来像卡住。
- shell 会先解释 `*`、`^`、`$` 等字符，表达式要用单引号包住；`dc -e 2 3 \* p` 仍可能被 shell 改写。
- 小数精度默认是 0：`dc -e '1 3 / p'` 得到 0 而不是 0.333，先执行 `10 k` 再算。
- 退出码只表示 dc 是否出错，不表示数值真假；需要判断结果时比较 `p` 的输出。
- `-5` 会被当成 dc 的选项，负数必须写成 `_5`。
